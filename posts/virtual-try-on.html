Virtual Try On Integration

I integrated the Fitting Box software with the website through API connection. I then created the user interface (UI) using CSS, HTML, and JavaScript. Using examples of best practices and what I knew to work I created a CTA button on the product page that when clicked initiated the try on function instance and allowed the user to see the eyewear on their face and choose different styles is available. When closing the try on screen pop up the try on session closed.

  1. Connected the virtual try on software to the website through API
  2. Created the pop up container that will display the fitting box user interface and allow the customer to try on the eyewear. For this I used HTML to structure the pop up container, and styled it to match the website theme and position it correctly on all screen sizes.
  3. Created the JavaScript functions to display the pop up when the CTA button is clicked and start the virtual try on software.
  4. Created the JavaScript functions to close the pop up and the virtual try on session when the exit button or escape is clicked.
